# Storybook

Package: `@otwld/ng-storybook`
Source path: `packages/storybook/ng/src/lib/storybook/storybook.ts`
Public import: `@otwld/ng-storybook`

`@otwld/ng-storybook` centralizes deterministic Storybook infrastructure for Angular source bricks:

- Common Angular application providers
- Router and Location doubles for focused stories
- PrimeNG and Tailwind theme mode decorators
- Viewport mode decorators
- MSW bootstrap and handler composition
- Seeded faker genetics data generation
- Reusable search/list endpoint mocks

This package is designed for stable Storybook test-runner and Chromatic visual regression snapshots.

## Preview Providers

Use `provideStorybookAngularApp(...)` for preview-level framework wiring. Story-specific providers can still be passed through the `providers` option.

```ts
import type { Preview } from '@storybook/angular';
import { provideStorybookAngularApp, withStorybookProviders } from '@otwld/ng-storybook';

const preview: Preview = {
  decorators: [
    withStorybookProviders([
      provideStorybookAngularApp({
        providers: [],
      }),
    ]),
  ],
};

export default preview;
```

## Router And Location Doubles

Use the shared doubles when a story needs a focused navigation spy without bootstrapping real routes.

```ts
import { provideStorybookLocation, provideStorybookRouter, withStorybookProviders } from '@otwld/ng-storybook';
import { fn } from 'storybook/test';

const navigate = fn();
const back = fn();

export default {
  decorators: [
    withStorybookProviders([
      provideStorybookRouter({ navigate }),
      provideStorybookLocation({ back }),
    ]),
  ],
};
```

## PrimeNG Theme Modes

PrimeNG defaults dark mode to the system media query. Storybook uses the root `.app-dark` class so toolbar-selected `light`, `dark`, and `system` modes apply the same way across PrimeNG and Tailwind.

```ts
import Aura from '@primeuix/themes/aura';
import { definePreset } from '@primeuix/themes';
import type { Preview } from '@storybook/angular';
import {
  provideStorybookPrimeNgTheme,
  storybookPrimeNgThemeGlobalTypes,
  withStorybookPrimeNgThemeMode,
  withStorybookProviders,
} from '@otwld/ng-storybook';

const BlueAura = definePreset(Aura, {});

const preview: Preview = {
  globalTypes: {
    ...storybookPrimeNgThemeGlobalTypes,
  },
  decorators: [
    withStorybookPrimeNgThemeMode({ defaultMode: 'dark' }),
    withStorybookProviders([provideStorybookPrimeNgTheme({ preset: BlueAura })]),
  ],
};

export default preview;
```

## MSW Preview Setup

```ts
import type { Preview } from '@storybook/angular';
import { createJsonGetHandler, createStorybookMswPreview, defineStorybookMswHandlers } from '@otwld/ng-storybook';

const mswPreview = createStorybookMswPreview(
  defineStorybookMswHandlers({
    candidates: [
      createJsonGetHandler('/api/recruitment/candidates/current', {
        id: 'candidate-current',
        fullName: 'Morgan Nguyen',
        skills: ['angular', 'typescript'],
      }),
    ],
  }),
);

const preview: Preview = {
  loaders: [...(mswPreview.loaders ?? [])],
  parameters: {
    ...(mswPreview.parameters ?? {}),
  },
};

export default preview;
```

## Seeded Faker Genetics (Stable Snapshots)

```ts
import { createFakerGenetics } from '@otwld/ng-storybook';

const genetics = createFakerGenetics({
  seed: 'chromatic-v1',
  refDate: '2026-01-01T00:00:00.000Z',
});

const buildCompany = genetics.defineEntityFactory('company', ({ faker, id, key }) => ({
  id: id('company', key),
  name: faker.company.name(),
}));

const buildCandidate = genetics.defineEntityFactory<{
  companyKey: string;
}>('candidate', ({ faker, id, key }, input) => ({
  id: id('candidate', key),
  companyId: id('company', input.companyKey),
  fullName: faker.person.fullName(),
}));
```

## Reusable Search Responses for MSW

```ts
import { createFakerGenetics, createMswSearchGetHandler, withStoryMswHandlers } from '@otwld/ng-storybook';

const genetics = createFakerGenetics({ seed: 1337 });
const companies = genetics.many(24, (index) => ({
  id: genetics.createId('company', index),
  name: `Recruiting Company ${index}`,
}));

const companySearchHandler = createMswSearchGetHandler(genetics, '/api/recruitment/companies/search', companies, {
  search: {
    searchBy: ['name'],
    sorters: { name: (item) => item.name },
  },
});

export const SearchSuccess = {
  parameters: {
    ...withStoryMswHandlers({
      companies: [companySearchHandler],
    }),
  },
};
```

`createMswSearchGetHandler(...)` reads URL params (`query`, `page`, `pageSize`, `sortBy`, `sortDirection`) and delegates filtering/sorting/pagination to `genetics.search(...)`.

## Conventions for Stable Visual Regression

1. Use fixed seeds (`seed: 'chromatic-...'`), never unseeded randomness.
2. Set `refDate` when using faker date utilities.
3. Build cross-entity references with deterministic IDs:
   - `id('company', companyKey)`
   - `id('candidate', candidateKey)`
4. Keep mock handlers composable through `parameters.msw.handlers` groups.
5. Prefer accessible roles and scoped `canvas` queries in play functions.
6. Keep reusable factory/search logic in `@otwld/ng-storybook`; keep scenario payload tweaks in stories.
