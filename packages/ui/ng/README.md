# @otwld/ng-ui

Reusable Angular UI primitives for Cortex Bricks applications.

## Source-Brick Status

This package is source intended for inspection and future `bricks` CLI
consumption. It is not the primary compiled-package installation surface while
Cortex Bricks remains in prerelease.

## Public Surface

- Standalone components for common display and interaction patterns.
- Directives for scroll, visibility, sticky class, and viewport-driven UI
  behavior.
- Small services that support browser UI primitives.

## Development Checks

- `pnpm exec nx lint ng-ui`
- `pnpm exec nx test ng-ui`
- `pnpm exec nx build ng-ui`
