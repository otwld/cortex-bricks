# DeepPartial

Recursive partial type for nested object structures.

```ts
type DeepPartial<T> = T extends object ? { [P in keyof T]?: DeepPartial<T[P]> } : T;
```

## Example

```ts
type JobOfferPatch = DeepPartial<JobOffer>;
```
