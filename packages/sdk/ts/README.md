# @otwld/ts-sdk

Framework-neutral TypeScript helpers used by Cortex Bricks packages.

## Source-Brick Status

This package is source intended for inspection and future `bricks` CLI
consumption. It is not the primary compiled-package installation surface while
Cortex Bricks remains in prerelease.

## Public Surface

- Pagination and range contracts.
- Nested path, object, primitive, slug, shortcut, and utility type helpers.

## Development Checks

- `pnpm exec nx test ts-sdk`
- `pnpm exec nx typecheck ts-sdk`
- `pnpm exec nx build ts-sdk`
