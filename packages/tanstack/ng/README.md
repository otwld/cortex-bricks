# @otwld/ng-tanstack

Angular helpers for TanStack Query usage in Cortex Bricks applications.

## Source-Brick Status

This package is source intended for inspection and future `bricks` CLI
consumption. It is not the primary compiled-package installation surface while
Cortex Bricks remains in prerelease.

## Public Surface

- Query key and query option helpers.
- Skippable query helpers and async operation utilities.
- Mutation and load-more directives for Angular UI integration.

## Development Checks

- `pnpm exec nx lint ng-tanstack`
- `pnpm exec nx test ng-tanstack`
- `pnpm exec nx build ng-tanstack`
