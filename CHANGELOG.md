# Changelog

## v0.1.0 - Public Preview

Cortex Bricks is now positioned as a public preview source-brick repository for
Angular, NestJS, and framework-neutral TypeScript building blocks in Nx
monorepos.

### Added

- Public README positioning for Cortex Bricks as a source-brick repository.
- Preview documentation for the upcoming separate `bricks` CLI.
- MIT license file for public repository use.

### Notes

- The supported external workflow is browse-only until the `bricks` CLI is
  ready.
- The `bricks` CLI is planned to consume source-brick repositories like this one
  and copy, paste, sync, and eventually three-way-merge source files into user
  Nx monorepos.
- APIs, brick names, package boundaries, and implementation details may change
  during the preview period.
